# Face Sketch Maker

## Description
A Python project that converts photos into pencil sketch drawings using OpenCV image processing techniques. The application applies grayscale conversion, inversion, and Gaussian blur to create a realistic pencil sketch effect.

## Technologies
- Python
- OpenCV
- NumPy
- Jupyter Notebook

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/tabasam409/Face-Sketch-Maker.git
   cd Face-Sketch-Maker
   ```
2. Install dependencies:
   ```bash
   pip install opencv-python numpy
   ```
3. Open and run the Jupyter Notebook:
   ```bash
   jupyter notebook Face_Sketch_Maker.ipynb
   ```
